Privacy Policy

Last updated: August 13, 2026

Project Chaos Interactive (PCI) is a desktop application for interactive live-stream experiences. This policy describes the information handled by the application.

TikTok authorization

When enabled, PCI uses TikTok Login Kit so a user can authorize access to basic profile information. PCI does not request or store the user's TikTok password. Authorization can be revoked through TikTok.

Information handled

PCI may handle the TikTok profile information and live configuration needed to connect the creator's account, as well as local project, alert and sound configuration. Information is used to provide the features selected by the user.

Local storage and third parties

Desktop configuration is stored locally unless a connected service is explicitly used. TikTok and other integrations process information under their own privacy policies.

Security and deletion

Do not share API keys or other credentials. Users may disconnect integrations and remove local PCI data using the application or their operating system.

Contact

For privacy questions, use the support channel provided with the official PCI distribution or repository.
