Project Chaos Interactive

Interactive tools for TikTok LIVE creators.

What PCI does

PCI connects audience events from TikTok LIVE with interactive games, alerts, sounds, overlays and other creator experiences.

The app asks users to authorize their TikTok account through TikTok Login Kit when that feature is enabled. TikTok credentials are entered on TikTok and are not requested or stored by PCI.
